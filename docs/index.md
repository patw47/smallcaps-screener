# SmallCaps Screener

One product: a Telegram alert after an earnings release whose seasonal surprise (SUE) is in
the top quintile, on US micro caps, and a page that lists the alerts with the returns realized
afterwards. It does **not** trade and is not financial advice. The page is in French and
English; this documentation is in English.

See the [project README](https://github.com/patw47/smallcaps-screener) for the mechanism, the
limits and how to read the page. This site covers:

the removal of the scan. The measured values of the current thesis live outside this repo and
are never published.
